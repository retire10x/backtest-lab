  간단/자세히 둘 다 노출. 설명 캡션 문단들만 간단 모드에서 압축.
- `#strategy`: 규칙 4줄 리스트는 이미 짧아서 그대로 둬도 됨. Q&A
  박스(고점 하락 질문)와 "한계" 긴 문단은 간단 모드에선 짧은 불릿
  3~4개로(예: "최근 상승장 편중", "일부 해는 예금보다 낮음", "급락
  초반 반응 느림", "10년 데이터·2008 위기 미검증"), 자세히
  모드에서 지금 산문 유지.

**구현 방식**: 저번 지시와 동일하게 새 라이브러리 없이 CSS class +
짧은 JS로. 다만 이번엔 "섹션 통째로 숨기기"가 아니라, **문단/캡션
단위로 간단 버전(불릿·짧은 문장) / 자세히 버전(지금 산문) 두 개를
같이 넣어두고 토글**하는 구조. 예:
```html
<p class="detail-only">지금 있는 긴 설명 문단...</p>
<ul class="simple-only">
  <li>짧은 요약 불릿 1</li>
  <li>짧은 요약 불릿 2</li>
</ul>
```
`body.mode-simple .detail-only { display:none }`,
`body.mode-detail .simple-only { display:none }` 식으로 CSS 두
줄이면 됨. 기본 상태(첫 접속, JS 실행 전 서버 렌더 시점)는
`mode-simple`이어야 함. 상단에 "자세히 보기 ↔ 간단히 보기" 토글
버튼 하나는 이전 지시와 동일하게 유지. 면책 문구는 두 버전 모두
항상 노출(변경 없음).
